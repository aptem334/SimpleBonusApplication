# T-006 — Интеграционные тесты: сценарная таблица

**Status:** todo
**Priority:** medium
**Component:** docs

## Контекст
Юнит-тесты покрывают состояния, но не покрывают сквозной сценарий «несколько покупок подряд
с пересчётом баланса». Именно там обычно и живут дефекты округления и накопления.

## Требование
Таблица сценариев «канал + сумма → ожидаемые бонусы, комиссия, балансы»,
покрытая интеграционными тестами через MockMvc, включая последовательные покупки.

## Критерии приёмки
- [ ] Таблица сценариев лежит в `docs/DOMAIN.md` и покрыта тестами 1:1
- [ ] Есть кейсы: 15.00 Shop (бонус + комиссия), 19.99, 20.00, 299.99, 300.00, 300.01, 400.00
- [ ] Есть кейс последовательных покупок с накоплением бонуса
- [ ] Проверяется округление на «некруглых» суммах
- [ ] `./mvnw clean verify` зелёный
