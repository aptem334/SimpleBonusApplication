# T-005 — REST API и маппинг ошибок

**Status:** todo
**Priority:** high
**Component:** controller

## Контекст
Осталось выставить наружу три эндпоинта из ТЗ и превратить доменные исключения
в HTTP 400 с внятным описанием. Ответы на GET-балансы — GET с телом-числом.

## Требование
`GET /api/payment/{Shop|Online}/{amount}` → 200 без тела.
`GET /api/money`, `GET /api/bankAccountOfEMoney`, `GET /api/commission` → 200 со значением.
Любая доменная ошибка → 400 с описанием, а не 500 со стектрейсом.

## Критерии приёмки
- [ ] Три эндпоинта из ТЗ работают
- [ ] `@RestControllerAdvice` ловит доменные исключения → 400 + текст ошибки
- [ ] Некорректная сумма (`abc`, `-5`, `0`) → 400 с описанием
- [ ] Неизвестный канал (`Market`) → 400 с описанием
- [ ] Недостаток средств → 400 с описанием
- [ ] Тесты через MockMvc на каждый случай
- [ ] `./mvnw clean verify` зелёный
